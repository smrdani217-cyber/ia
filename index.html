    Como usar o Terço Virtual

    1. Pressione Iniciar terço para começar pela oração inicial.
    2. Toque em qualquer conta do rosário para abrir a oração daquela etapa.
    3. Use Anterior e Próxima para seguir a sequência.
    4. Escolha os mistérios para visualizar os temas de meditação.

    As orações e a sequência podem variar um pouco conforme a orientação da comunidade. Confirme o uso com a catequista.
